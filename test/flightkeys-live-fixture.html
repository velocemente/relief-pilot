FlightKeys live-plan parser test

Local acceptance harness for ofp-flightkeys. Select a live FlightKeys PDF; extraction and parsing run in this browser tab. The PDF is not uploaded to a server.

1. Select a FlightKeys PDF

PDF.js is pinned to 3.11.174. Internet access is needed to load the pinned PDF.js library unless it is served locally.

2. Optional expected-values file

Upload a JSON file containing independently verified values to compare with the parser output. Use dotted paths, e.g. {"expected":{"fltNum":"GTI874/02","blockFuelRaw":"120000"}}. Only supplied keys are compared.
